# Petal Chan website

This repository contains the public website for [Petal Chan](https://petalchan.com/), a privacy-first period and cycle tracker shipped on iOS and Android.

The website explains the product, links to the stores, and documents the privacy and offline-first approach. It is the product website source, not the private mobile application source.

## Stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- GitHub Pages deployment

## Run locally

Requirements: Node.js and npm.

~~~bash
npm install
npm run dev
~~~

Open http://localhost:3000. The repository also includes the public static output and the app-association files used by the site.
